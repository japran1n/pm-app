- **Cards**: `bg-card border border-border rounded-md shadow-xs` — shadow-xs ONLY on cards

- **Separator**: use `bg-border` (the `var(--border)` OKLCH value)

### badge.tsx
File: `components/ui/badge.tsx`

Rewrite the Badge component to match Supabase anatomy exactly:
- Shape: NOT rounded-full. Use `rounded-md` (same radius as cards)
- Text: UPPERCASE, 9px (`text-[9px]`), `tracking-[0.07em]`, `font-medium` (weight 500)
- Padding: `px-[5.5px] py-[3px]`
- Border: `border border-current/20` (1px border at 20% opacity of text color)
- Fill: `bg-current/10` (10% tint of the text color)
- No color dot (no `::before` circle)

Variant color mapping:
- `default` / `secondary`: `text-foreground`
- `warning`: `text-warning`
- `destructive`: `text-destructive`
- `success` / `brand`: `text-brand` (maps to `hsl(var(--brand-default))` or `var(--primary)`)
- `outline`: `text-foreground border-border bg-transparent`

```tsx
const badgeVariants = cva(
  "inline-flex items-center rounded-md border border-current/20 bg-current/10 px-[5.5px] py-[3px] text-[9px] font-medium uppercase tracking-[0.07em] transition-colors focus:outline-none focus:ring-2 focus:ring-ring focus:ring-offset-2",
  {
    variants: {
      variant: {
        default: "text-foreground",
        secondary: "text-muted-foreground",
        destructive: "text-destructive",
        warning: "text-warning",
        success: "text-brand",
        outline: "border-border bg-transparent text-foreground",
      },
    },
    defaultVariants: { variant: "default" },
  }
)
```
