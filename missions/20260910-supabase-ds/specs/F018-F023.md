## Key architectural fact
pm-app uses `@base-ui/react` 1.7.0 primitives (NOT Radix). The design lives in
`cva` strings. We copy Supabase's cva strings but keep the Base UI wrapper components.

Base UI state attributes differ from Radix:
- Base UI: `aria-expanded`, `aria-checked`, `aria-selected`, `data-popup-open`, `data-checked`
- Radix: `data-[state=open]`, `data-[state=checked]`, `data-[state=selected]`
- When porting Supabase cva strings, convert Radix `data-[state=*]` selectors to the
  Base UI equivalents shown above.

## Supabase Button Anatomy (from CLAUDE.md + lab)
- `rounded-md` on ALL variants
- Border on EVERY variant including primary: `border border-border` (primary gets `border-transparent` with bg fill but border is still there)
- `duration-200` transition
- `motion-safe:active:scale-[0.97]` press effect
- Sizes from Supabase constants: tiny 26px, small 34px, medium 38px, large 42px, xlarge 50px
- Hover: border moves UP — `hover:border-border-control-hover` on bordered variants
- Primary: `bg-primary text-primary-foreground` with `hover:bg-primary/90`
- Default (secondary in Supabase): `bg-secondary border border-border hover:bg-accent hover:border-border-control-hover`
- Outline: `bg-transparent border border-border hover:bg-accent hover:border-border-control-hover`
- Ghost: `bg-transparent border-transparent hover:bg-accent hover:border-border-control-hover`
- Dashed: `bg-transparent border border-dashed border-border hover:border-border-control-hover`
- Destructive: `bg-destructive/10 border border-destructive/30 text-destructive hover:bg-destructive/20 hover:border-destructive`
- Text/link: no border, no background, underline on hover
