## The Three Rules for Phase F
Every feature surface receives exactly these three treatments:

### Rule 1: Data is mono
Any element displaying machine data gets `font-mono` class:
- Dates and times (e.g., "Sep 10, 2026", "14:32")
- Timestamps and durations ("2h 30m", "3 days ago")
- IDs and keys (project codes, task IDs)
- Email addresses
- Counts and amounts ("€1,250.00", "42 tasks")
- Percentages that are data ("67%")

Add `font-mono` to the className of these elements. Do NOT add it to labels, headings, or button text.

### Rule 2: Space opens up
Page headers: `p-6 pt-4 lg:p-8 lg:pt-8`
Section containers: `px-6 lg:px-12` (or match existing padding but upgrade to the standard)
Table edge cells: `first:pl-6 lg:first:pl-8 last:pr-6 lg:last:pr-8`
This was already applied to `table.tsx` but check feature-specific tables/lists.

### Rule 3: Hover moves to the border
Rows, cards: replace `hover:bg-accent` / `hover:bg-muted` background-only hover with `hover-lift` pattern when the element is card-like, or `hover:border-border-control-hover` when it's a row.
The CSS classes `.hover-lift` and `.hover-surface` are in globals.css.
- Card-like clickable surfaces: add `hover-lift` class
- Row-like items (list rows, table rows): add `hover:bg-muted/50` (Supabase row hover is muted/50, NOT a full fill)
