## Decisions made
- F028 Board: task-card.tsx's onClick hover changed from a hardcoded `hover:bg-[#ffffff0d]` flat tint to `hover-lift` (card-like clickable surface per Rule 3). Board column task counts, card due dates, logged-time, subtask counts, and completion percentage all got `font-mono`.
- F029 List view: task-list-table.tsx's child-row hex hover literal replaced with `hover:bg-muted/50`; default TableRow hover in components/ui/table.tsx already matched the spec (`hover:bg-muted/50`), so no change needed there. list-due-date-cell.tsx's displayed date wrapped in a `font-mono` span (view-only span, not the editable `<Input type="date">`, which already inherits standard styling).
- F030 Task detail: due/start date `<Input type="date">` fields got `font-mono` class (the visible date text is the "data"). Activity feed relative-timestamp `<time>` got `font-mono`. The scrollable content container padding was upgraded from `px-6 py-6` to the spec's `p-6 pt-4 lg:p-8 lg:pt-8` — chosen over the SheetHeader (which stays `p-0`/sticky-specific) since that's the surface holding the actual field content.
- F031 Checklist/time-tracking/attachments: checklist "N of M checked" counter, time-tracking total/estimate/entry durations and dates (including the manual-log and edit-entry number/date inputs) all got `font-mono`. attachment-list.tsx has no rendered file-size or raw-date text today (only uploader name and filename) — no change made there; flagged in Out-of-scope below in case a future feature adds a size/date display.
- F032 My tasks: my-task-row.tsx's due-date cell font-mono was missing (other numeric cells already had it) — added. Page header padding upgraded to spec; section "(N)" counts wrapped in `font-mono`.
- F033 Dashboard: kpi-tile.tsx switched from a bespoke `hover:ring-foreground/20` to `.hover-lift`, and its big metric number got `font-mono`. priority-bar-chart.tsx and status-pie-chart.tsx are NOT actual Recharts SVG (repo-wide grep confirms Recharts has exactly zero remaining consumers — an earlier accessibility audit, F087, already rewrote both to plain DOM/button markup) — their count/percentage text is plain `<span>`s, so ordinary Tailwind `font-mono` was used instead of the spec's inline-style Recharts fallback. Dashboard root page header padding upgraded to spec.
- F034 Projects: project cards in the projects list got `.hover-lift` (card-like) and the open-task-count badge number got `font-mono`. Project detail layout header padding upgraded; the "Xh logged (Yh billable) of Zh estimated" line got `font-mono`.
- F035 Budget/measurement/team-hours panels: every numeric/date value across budget-panel.tsx (period dates, sold hours, rate, currency, spent-preview) and measurement-panel.tsx (baseline/target values, baseline date, snapshot value/date, frozen-baseline date) got `font-mono`, including on the underlying `<Input>` elements (date/number inputs render their own value as the "data"). team-hours-view.tsx budget-usage numbers, per-row duration/date table cells, and the "All entries (N)" heading total got `font-mono`. Added `hover:bg-muted/50` to budget-row and non-editable metric/improvement summary rows (viewer-mode list items) since those are row-like list items, not editable inline-form cards.
- None of these three files use an actual `<table>`/`TableCell` for the budget list (they're `<li>`/`<div>` based), so "edge padding first:pl-6" from the spec doesn't apply structurally — only team-hours-view.tsx's "All entries" section uses the real `<Table>` primitive, which already inherits the edge padding from the already-fixed `table.tsx` primitive.
