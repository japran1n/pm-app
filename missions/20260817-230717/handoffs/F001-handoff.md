Verified a second `next dev` boot no longer touches `CLAUDE.md`.
- Added `*.tsbuildinfo` to `.gitignore` (generated by `tsc --noEmit`, not meant to be committed).
- Left the default `public/*.svg` placeholder assets from create-next-app in place as harmless skeleton content; not part of app UI beyond the (now-removed) demo page.
