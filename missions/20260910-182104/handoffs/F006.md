## Decisions made
- `lib/queries/architecture.ts`'s `BoardPage` type had no `description` field — pages are tasks (standing decision 1), and `tasks.description` is documented DEPRECATED/read-only, with `tasks.description_text` being the maintained plain-text projection (see `20260822090000_task_description_json.sql`). Added `description: string | null` to `BoardPage`, selected `description_text` in `TASK_COLUMNS`/`TaskRow`, and mapped empty string to `null` in `buildBoardFromRows`. This is the minimal change needed to make AS-021 satisfiable; it does not touch the deprecated `description` column and does not add a new reader of it. `getArchitectureBoardForClient` picks this up automatically since both functions share `buildBoardFromRows`.
- Static/CMS badge (F007) and "Add section" trigger (F013) slots are empty `<div>`s in the column header, per the feature spec's explicit placeholder instruction, so those features only fill a slot rather than restructure the header.
- Sections render as flat title-only rows for now; F008 builds the full section card.
- `ArchitectureBoard`'s `components` prop is accepted and threaded through (unused this feature) so later features (hover highlighting, component tray) don't need to change its public contract; a `void components;` line satisfies the unused-var lint rule without disabling it.
