## Decisions made
- Followed the exact structural pattern already used for `--warning`/`--destructive`/`--info` (hue derived via `clamp(min, calc(base + (primary-hue - brand-hue-reference) * status-hue-pull), max)`, base colour via `oklch(lightness chroma hue)`, foreground via the same `clamp(0.12, calc((0.62 - l) * 100), 0.99)` contrast formula, border via `oklch(from var(--x) l c h / 30%)`).
- Introduced `--component-lightness` / `--cms-lightness` helper knobs (0.75 default in `:root`, mirrored explicitly in `[data-theme='dark']`/`.dark`, overridden to 0.55 / 0.58 in `[data-theme='light']`/`.light`) — this mirrors the existing `--warning-lightness`/`--destructive-lightness`/`--info-lightness` convention exactly, so both AS-075..078 and AS-079 hold without inventing a new organising scheme.
- `--component-hue` targets green (clamp 130–160, base 142) to read as Webflow's component green; `--cms-hue` targets purple/lilac (clamp 270–305, base 285) to read as Webflow's CMS colour. Chose these ranges by eye against Webflow's actual component/CMS badge hues while keeping the same hue-pull derivation mechanism as `--warning-hue`/`--destructive-hue`/`--info-hue`.
- `--component-border-hover` / `--cms-border-hover` use 50% alpha (vs 30% for the plain border) to give a visible lift on hover, consistent with the "Hover lifts the border" interaction rule in CLAUDE.md.
- Added matching `--color-component*` / `--color-cms*` entries to the `@theme inline` block so Tailwind utilities (`bg-component`, `text-cms-foreground`, etc.) are available to the worker who builds the Architecture board UI — this is additive only, no existing mapping touched.
- The repo's actual theming convention is class/attribute selectors (`[data-theme='dark'], .dark` and `[data-theme='light'], .light`), not a `prefers-color-scheme` media query — there is no `:root:not([data-theme="light"])` pattern anywhere in the file. I followed the file's real convention rather than inventing a media-query block that doesn't exist elsewhere, per the "follow the exact structural pattern the file already uses" constraint.
