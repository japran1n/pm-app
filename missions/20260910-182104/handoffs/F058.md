## Decisions made
- Computed `firstUnanswered` via `questions.findIndex` matching on `questionId` against `initialAnswers`, treating an answer as "present" when `answerText` is truthy (non-empty) OR `answerOptions` has at least one entry — this covers both free-text and choice-type questions per the clarified spec.
- When `findIndex` returns -1 (every question answered), resume at the last question (`questions.length - 1`, floored at 0 for an empty question list) rather than index 0, since starting over would contradict "resume" semantics.
- Updated the pre-existing F055 "pre-fills the answer stub" test to use its own single-question array instead of the shared 3-question fixture, since giving q1 an answer under the new resume logic now correctly moves `currentIndex` off q1 — the test's original intent (prefill works for the current question) is preserved by isolating it from the multi-question resume behavior, which is now covered by the new F058 test file instead.
