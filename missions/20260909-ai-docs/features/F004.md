# F004 — Tool: search_docs

## Goal
Let the model find documents it was not handed.

## Files
- `lib/ai/tools/search-docs.ts` (new)
- `lib/ai/tools/__tests__/search-docs.test.ts` (new)

## Input
`{ query: string; projectId?: string }`

## Output data
`{ results: Array<{ docId, title, folderName, snippet }> }` — max 10.

## Rules
- Workspace-scoped always; `projectId` narrows further when given.
- Snippet: ~200 chars around the first match, or the document's opening if the match
  was in the title. Never return the whole body — that is what `get_current_doc` is for.
- Empty result set returns `ToolEmpty` / `no_results`, not an empty ok.
- Prefer reusing whatever search helper already exists in `lib/actions` or
  `lib/queries` before writing new SQL. Look first; do not duplicate.

## Assertions
AS-022, AS-023, AS-008, AS-028

## Out of scope
Vector / semantic search. That is a later mission — keyword only here.
