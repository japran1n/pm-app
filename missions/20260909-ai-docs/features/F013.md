# F013 — Empty state + suggestions

## Files
- edit `components/ai/assistant-sidebar.tsx`

## Rules
- Two or three sentences saying what the assistant can and cannot do. State the
  documents-only limit here, plainly — it sets expectations before the first
  refusal has to.
- At least three suggestion chips. They must be genuinely useful defaults, not
  feature advertising. Ground them in the current doc when there is one:
  - "What's missing before I send this to the client?"
  - "Shorten the introduction"
  - "Draft a new doc from material I'll paste"
- Clicking a chip submits it immediately (AS-068).
- Chips are buttons, keyboard reachable, visible focus ring.
