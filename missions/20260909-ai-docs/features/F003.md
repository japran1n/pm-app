# F003 — Tool: get_current_doc

## Goal
Read one document the caller is allowed to see, and nothing else.

## Files
- `lib/ai/tools/get-current-doc.ts` (new)
- `lib/ai/tools/__tests__/get-current-doc.test.ts` (new)

## Input
`{ docId: string }` (uuid)

## Output data
`{ docId, title, markdown, folderName, clientVisible, wordCount }`

## Rules
- Use the RLS-respecting `createClient()` from `lib/supabase/server`. **Never** a
  service-role client (AS-001, AS-002).
- Not found, or found-but-RLS-invisible, both return `ToolEmpty` with the right
  `reason`. Do not distinguish them in the message — that would leak existence.
- `wordCount` is computed from markdown, not stored.
- Truncate `markdown` at 40 000 characters and set a `truncated: true` flag rather
  than blowing up the model's context.

## Assertions
AS-020, AS-021, AS-002, AS-008, AS-028

## Tests (all three are required by AS-028)
1. Happy path — doc the caller can see returns ok with correct fields.
2. Empty path — nonexistent uuid returns `empty` / `not_found`.
3. Isolation — a doc in another workspace returns `empty`, never its content.

## Out of scope
Fetching related tasks, comments or activity. Documents only.
