# F012 — Composer

## Files
- `components/ai/assistant-composer.tsx` (new)

## Rules
- Auto-growing textarea, capped at ~6 rows then scrolls.
- Enter submits; Shift+Enter newline. On touch/narrow viewports Enter must insert a
  newline instead — check how the existing chat composer in `components/chat` handles
  this and match it rather than inventing a second convention.
- While streaming: input disabled, submit replaced by a Stop control wired to `stop()`.
- When `hasApiKey()` is false: disabled, with one explanatory sentence and no error styling
  — this is a configuration state, not a failure (AS-071).
- Below the input, a quiet meta row: model name and the running cost/token count for the
  thread. Use `--text-quaternary` here — this is exactly the decorative case it is for.

## Assertions
AS-067, AS-069, AS-071

## Out of scope
Sending files or images.
