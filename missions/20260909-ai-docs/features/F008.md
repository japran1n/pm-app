# F008 — Client stream parser hook

## Goal
Turn the NDJSON stream into React state. No JSX in this file.

## Files
- `lib/ai/use-doc-assistant.ts` (new)

## API
```ts
useDocAssistant({ currentDocId }) => {
  messages: AssistantMessage[];   // user + assistant turns, in order
  toolCalls: ToolCallView[];      // keyed by id, start/end merged
  proposals: ProposalView[];      // pending | accepted | rejected
  isStreaming: boolean;
  error: { code: string; message: string } | null;
  send(text: string): void;
  stop(): void;
  reset(): void;
}
```

## Parsing rules
- Read the body with `response.body.getReader()` and a `TextDecoder`. **Buffer across
  chunk boundaries** — a JSON object will be split mid-line and naive
  `chunk.split("\n")` will throw. Keep a `buffer` string, split on `\n`, keep the
  trailing partial for the next chunk. This is the single most common bug here.
- Ignore unknown `t` values rather than throwing — forward compatibility.
- `stop()` calls `AbortController.abort()`; the partial assistant text stays visible.
- `text` deltas append to the last assistant message, creating one if needed.
