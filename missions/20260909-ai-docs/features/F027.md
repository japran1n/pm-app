# F027 — Scope tools to the current workspace (M1c, AS-023/AS-024)

## The gap
`docs_select_active_members` (`20260904010000_docs_system.sql:120-124`) uses
`is_active_workspace_member(workspace_id)` — it scopes to **every workspace the user belongs to**.
The contract says the caller's **current** workspace:
- AS-023 "`search_docs` restricts results to the caller's current workspace."
- AS-024 "`list_doc_templates` returns only ... for the caller's workspace."

Neither tool accepts a workspace id at all (`search-docs.ts:51-54`, `list-doc-templates.ts:42`).
A user in three workspaces gets documents from all three interleaved, with no `workspace_id` on
the result rows to tell them apart.

The three tools wrote long comments justifying this, but those comments conflate "not another
user's workspace" (true, and AS-008 survives) with "the current workspace" (false). Different claims.

The repo's own convention is the opposite: `lib/queries/docs.ts:163` does `query.eq("workspace_id", workspaceId)`.

## Fix — make the code match the contract, not the reverse
The validation contract is immutable. AS-023/AS-024 say "current workspace", so implement that.

- Thread `workspaceId` from the route (it already resolves the caller's workspace) into
  `buildDocsAgentRequest` and down into the tools.
- Add `.eq("workspace_id", workspaceId)` to `search_docs` and `list_doc_templates`.
- `get_current_doc`: verify the doc belongs to the current workspace; if not, return the same
  `ToolEmpty` / `not_found` as any other invisible doc — **the message and reason must stay
  identical**, or you reintroduce the existence leak AS-021 currently passes cleanly.
- Do not weaken RLS. This is defence in depth on top of it, exactly as `lib/queries/docs.ts` does.

## Tests
Extend F024's real-DB integration tests: a user who is an active member of **both** workspace A
and workspace B, calling with A as current, must not see B's document or B's doc-template.

This is the case the current tests cannot reach — they only prove a stranger sees nothing, which
RLS already guaranteed. This one proves the *scoping*, which nothing currently does.

## Assertions
