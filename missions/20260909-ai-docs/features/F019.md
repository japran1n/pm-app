# F019 — Thread persistence

## Files
- `lib/actions/ai-threads.ts` (new)
- edits to `lib/ai/use-doc-assistant.ts` and the sidebar

## Rules
- Load the most recent thread for the current workspace on mount; render its messages
  in order (AS-082).
- Persist the user turn immediately on send, and the assistant turn when the stream
  reaches `done` (or on abort, with whatever text arrived — a stopped answer is still
  worth keeping).
- Tool calls and proposals persist with enough detail to re-render (AS-084).
- A settled proposal reloads as settled. Never offer Accept twice for the same
  `proposalId` (AS-085) — this is the assertion most likely to be missed, and the
  failure mode is a duplicate write.
- "New chat" creates a new thread; the old one remains (AS-083).

## Assertions
AS-082, AS-083, AS-084, AS-085
