# F010 — Message thread rendering

## Files
- `components/ai/assistant-thread.tsx` (new)

## Rules
- User turns: subtle raised bubble, right-aligned. Assistant turns: plain text on the
  panel ground, no bubble — it is the dominant voice and a bubble makes it noisy.
- Assistant text is markdown. Reuse whatever markdown renderer the docs feature already
  uses (`tiptap-markdown` / the existing `markdown-editor.tsx` path) before adding a
  dependency. Look first.
- **Auto-scroll that does not fight the user**: stick to bottom only while the user is
  already within ~40px of the bottom. If they have scrolled up to read, do not yank them
  down on every token. Show a "jump to latest" affordance instead.
- `aria-live="polite"` on the thread container; not `assertive`.
