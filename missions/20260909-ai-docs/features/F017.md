# F017 — Tool: create_doc + Save

## Files
- `lib/ai/tools/create-doc.ts` (new)
- `lib/ai/tools/__tests__/create-doc.test.ts` (new)
- extend `lib/actions/ai-proposals.ts` with `saveDocDraft(...)`
- a draft preview surface in the sidebar

## Behaviour
- Tool takes `{ title?, templateId?, sourceMaterial }` and returns a `DocCreateProposal`.
  It **writes nothing** (the no-writes test from F014 covers this file too).
- When a template is chosen, its sections and rules drive the structure. Honour the
  rules literally — especially "flag a gap rather than invent a value". A draft that
  marks `OWNER?` is more useful than one that guesses a name.
- Save calls the existing `createDoc` action with the chosen folder, then navigates to
  the new doc.

## Rules
- Folder defaults to the template's `folderHint`, else the currently open doc's folder,
  else the project's Docs root. Never silently create at workspace root.
- `client_visible` defaults to **false** for AI-drafted documents regardless of template,
  unless the template explicitly sets it. Defaulting a machine-drafted document to
  client-visible is the kind of mistake that is expensive exactly once.
