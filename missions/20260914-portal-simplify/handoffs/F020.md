## Decisions made
- Root cause of the clipping was `shrink-0` on every mobile nav row (`NavRow` and the `ProjectNavGroup` toggle button): each row kept its own natural (font-driven) width regardless of the 375px strip's actual width, so the fourth row (Project) got pushed past the viewport edge. Fixed by making all four top-level mobile rows `flex-1 basis-0` so they always divide the strip's width evenly, instead of only shrinking padding/gap/type-size further (which was the F018 approach and still wasn't enough headroom once combined with the spec's `text-sm` label requirement).
- Gave every mobile row a fixed `h-10` (40px) height to satisfy the "tap targets >= 40px tall" requirement independent of `text-sm` line-height/padding math.
- Bumped mobile label size from `text-xs` back up to `text-sm` per this feature's explicit instruction ("labels readable (text-sm per design system)"), and compensated the extra width by tightening `gap-1 px-1.5` (down from `gap-1.5 px-2`) and dropping the chevron glyph entirely on mobile for the Project toggle (spec explicitly allows "drop the chevron on mobile"). `aria-expanded` on the button still exposes open/closed state to assistive tech, so nothing observable is lost.
- Icon size on mobile stays `size-3.5` (unchanged) — the width budget came from the layout change (flex-1/basis-0) and the dropped chevron, not from shrinking icons further, keeping them legible at 40px tap height.
- Left desktop `<aside>` sizing (`w-full`, `gap-2.5 px-3 py-2 text-sm`, chevron shown) completely untouched — this feature is mobile-only per spec.
- The Project group's *expanded* children row (the secondary items shown once the group is open) is unchanged from F018 and still renders as its own `shrink-0` horizontal sub-row appended after the toggle button; that's a distinct, already-scrollable state, not the collapsed 4-item fit this feature's assertion targets, so it was left alone.

## Out-of-scope work needed

A follow-up could give the expanded secondary row its own wrapping or a drawer-style disclosure if that's ever flagged.
