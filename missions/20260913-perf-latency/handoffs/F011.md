## Decisions made
- Rewrote the assigned-tasks query to start from `.from("task_assignees")` with `.eq("user_id", userId)` as the first predicate, embedding `tasks!inner(${TASK_SELECT_COLUMNS})` to join through to the task row, and moving the workspace/archived/trashed filters onto the dotted `tasks.projects.*` / `tasks.*` paths (same pattern the file already used for `projects.*` filters, just one level deeper).
