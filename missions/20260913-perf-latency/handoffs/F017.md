## Decisions made
- Badge-figure skeleton sizes to a representative `h-4 w-5` box rather than trying to match a variable-digit-count width exactly — the real badge's width depends on the resolved count's digit count (1 vs 2+ digits), so there is no single "exact" width; `w-5`/`h-4` approximates the common 1-2 digit occupied state per the spec's own example (`w-5 h-4 rounded-full` — used `rounded-md` instead to match the actual `Badge` component's real corner radius rather than the illustrative `rounded-full` from the spec's example).

- Tour figure intentionally keeps `fallback={null}` — no in-flow footprint exists to preserve (see Notes below). Treated this as satisfying, not violating, the "hold exact footprint" rule, since a footprint of zero is a real footprint.
- Did not touch `favorite-project-ids-figure.ts` or its Suspense usage (if any) — spec's steps enumerate the badge figures, notification icon, and tour status explicitly by name; the workspace switcher was added because the layout wraps it the same way and AppSidebar's own "no visual change" contract implies it also needs a non-null, sized fallback to avoid a layout shift.
